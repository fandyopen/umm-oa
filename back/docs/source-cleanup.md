# 全系统源码清理记录

日期：2026-11-02。

## 已清理

- 删除 64 个废弃源码和样式文件，包括旧用户、角色、部门、岗位管理页，旧商店、投标和客商列表，以及无人引用的布局、组件和生成器。
- 删除 89 个未被当前页面调用的前端 API 导出，清理失效隐藏路由和冗余转导出。
- 移除 14 个旧菜单及岗位管理接口；当前模块管理、角色授权及低代码岗位查询不变。
- 删除组织权限组件中的部门、成员直接授权分支，只保留角色授权。
- 删除注释掉的旧实现、无效主题换色选项和隐藏的表单代码导出状态，统一改动文件的格式。
- 移除 cesium、vue-cesium、vue-count-to、vue-infinite-scroll、vite-plugin-cesium，并同步 npm 和 pnpm 锁文件。
- 未知接口改为 HTTP 404 和业务码 404，避免假保存及假空列表。
- 更新路由地图、API 清单、管理员测试账号、项目首页说明与当前实现文档。

## 有意保留

- 客户合同的隐藏授权模块及历史书签跳转，仍与审批、回款、版本及提醒权限有关。
- 低代码表单、预览、流程设计和办理页面：它们通过其他页面进入。
- 历史单人审批的受限待办办理入口，新流程不能通过该入口绕过审批。
- 旧岗位记录、关联清理和低代码选择器的只读查询。
- 旧权限表的迁移读取、数据库升级脚本以及数据构建工具依赖的参考资料。

隐藏是展示属性，并不是删除依据。本轮依据固定路由、全局组件注册、版本内模块目录、当前数据库模块目录和源码调用链交叉核对；没有执行数据清理 SQL。

## 验证

- 前端生产构建通过。
- 后端完整测试通过：103 项，0 失败、0 错误。
- 扫描 54 个后端 Java 源文件，清理确认未使用的 import；未发现完全无引用的私有方法候选。
- npm run audit:source 通过：284 个源码文件均可达，无失效页面、缺失本地引用、缺失命名导出、废弃 API 导出或文档路径。
- npm、pnpm 锁文件的直接依赖及保留依赖图已核对；其余包版本保持不变。
- git diff --check 通过。

静态检查不替代业务验收，也不能据此删除未来新增的数据库自定义页面。审计工具及运行库目录补充方式见 [工具说明](../tools/README.md)。

本轮没有停止正在运行的后端。后端源码修改需要重新构建并手动重启服务后生效。
