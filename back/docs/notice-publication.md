# 通知公告

管理入口为“系统 → 通知公告”，阅读入口为 PC 首页“重要通知 / 更多”，以及 H5、小程序工作台和消息页的“通知公告”。

角色授权继续使用通知公告模块及新增、修改、删除动作。授权人员可直接发布，无需审批或超级管理员二次确认：创建并发布需要新增和修改权限，发布或撤下已有通知需要修改权限。普通员工仅可阅读本企业已发布内容，无需通知管理权限。

编辑页可直接“发布通知”，也可以“保存草稿”。保存为草稿不会向员工展示；修改已发布内容后保存草稿会停止展示，重新发布即可恢复。撤下后列表和详情均不再向员工开放。发布更新原公告，不创建重复记录；重复发布不会变更原发布时间。列表显示真实创建人、发布人和发布时间，支持标题、创建人、发布状态筛选与分页。

管理接口为 `/system/notice`，员工阅读接口为 `GET /notices`、`GET /notices/{id}`，均需登录。正文展示采用受限 HTML 渲染；PC 详情在禁用脚本的沙箱中展示，移动端使用允许列表生成富文本节点。公告不冒充审批待办，也不改变待办或抄送消息的阅读状态。

`NoticeSchemaMigration` 在 H2、MySQL 启动时补齐字段；历史公告保留为草稿，不会自动发布。新库结构已同步，存量 MySQL 也可执行 `db/mysql/notice-publication-upgrade.sql`。数据库升级不清空历史正文，不重置已发布或已撤下状态。
