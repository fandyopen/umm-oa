# 列表默认日期排序

有明确业务日期的业务列表按该日期倒序；相同日期再按创建时间和主键倒序。
空日期放最后。分页前完成排序，导出和移动端复用相同服务时遵循同样的顺序。

| 列表 | 优先日期 |
| --- | --- |
| 员工档案 | 入职日期 |
| 薪资标准、人事异动 | 生效日期 |
| 考勤批次、工资批次、工资条、提成核算批次 | 所属月份 |
| 考勤明细 | 考勤日期 |
| 计薪规则、提成规则 | 生效月份 / 生效日期 |
| 客户档案、成员管理、合同列表、职位管理 | 创建时间 |
| 客户跟进记录 | 跟进时间 |
| 商机列表 | 预计成交日期 |
| 人才库 | 最近联系时间 |
| 招聘流程 | 推荐日期 |
| 应收台账、手工应收 | 到期日期 |
| 回款、开票、退款、成本、核销与冲销 | 业务日期 |
| 实际到账流水 | 回款日期 |
| 催收计划 | 下次催收日期 |
| 审批流程配置 | 最近修改时间 |
| 待办、已办、抄送和发起记录 | 页面展示的创建时间 |
| 登录日志、操作日志 | 登录时间 / 操作时间 |
| 角色列表、字典类型、参数配置、通知公告 | 创建时间 |

数据表管理优先采用已登记表的上述业务日期，没有业务日期则使用创建时间等可用时间字段，最后回退到主键。用户手工点击表头选择的排序优先，主键参与同值排序以保持分页稳定。

以下内容使用业务本身的顺序：菜单和组织树、岗位和字典选项的人工排序、按钮排序、审批节点与过程时间轴、业绩排名、金额计算过程中的锁定和依赖顺序。待办消息来源目录没有日期字段，按所属模块分组。

验证使用独立 H2 测试库，不对本地业务数据执行更新或迁移。
