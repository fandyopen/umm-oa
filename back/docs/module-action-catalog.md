# 模块动作目录

模块授权表示可以进入页面、查看列表和详情。动作权限只对应页面上的真实操作。

内置动作由 `ModuleActionService` 在启动时同步到 `sys_module_action`，运行时不会
删除自定义动作。自定义动作可在“系统 -> 流程设置 -> 动作管理”中维护，并配置
`handlerKey` 与 JSON 执行器参数。
