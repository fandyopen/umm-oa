# 代审批

入口：待办 → 代审批（模块 341600）。默认仅固定超级管理员可见。

在角色管理中为系统管理员、总经办或其他需要监管审批的角色勾选“代审批”模块，即可查看当前企业所有部门的流程审批。另勾选该模块的“代审批”按钮，才可同意或驳回当前节点。仅勾选按钮、未勾选页面不能使用接口；撤销授权后立即生效。

列表默认展示待审批任务，可切换已审批、全部。每行是一个审批节点，支持按审批部门（含下级）、指定审批人、发起人、业务模块、发起日期及关键词查询。只从统一流程的实际审批任务读取，不收录业务提醒、发放工资、查阅工资条、交接、抄送等普通消息。

详情展示申请内容和所有节点记录：发起人、指定审批人及部门、实际审批人、结果、时间、意见。代审批保留原分配人，实际操作人来自服务端登录身份。审批通过后继续原节点流转，全部通过才执行原业务；驳回终止本次流程。保留原业务状态、版本及金额等验证。固定超级管理员可通过此页面代审本人发起的申请；其他获授权角色仍不能处理本人发起的申请。该豁免由服务端核验超级管理员身份，仅在本次代审批操作内生效。

新办理记录保存在 `oa_approval_decision`，与任务完成及业务执行处于同一事务。历史记录优先读取原审批评论中的操作人，缺少证据时显示“历史记录未记载”，不推断操作人。

本地 H2 启动自动执行增量脚本。已有 MySQL 库执行 `back/db/mysql/upgrade-approval-inbox.sql` 后重启；全新 MySQL 初始化脚本也包含此表与菜单。
