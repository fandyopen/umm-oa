# 合同作废、终止和删除

列表右侧「更多」及合同详情均提供状态对应的操作。作废合同（void）、终止合同（terminate）、撤回审批（withdraw）、删除合同（remove）分别通过「模块管理 → 合同列表」授权。作废与终止已接入统一业务执行器，可以开启流程设计并发布启用审批；只开启设计、保存草稿或未发布不产生审批。

* 从未生效的草稿、已退回、待签署合同：填写原因作废，再删除。
* 审批中的合同：先撤回，旧流程、审批历史保留，未办理任务停止。合同内容审批撤回后回到草稿；签署、作废或终止审批撤回后保留原业务状态。
* 已有生效版本：不能通过作废草稿绕过原合同履约。先关闭或完成关联职位，再终止合同；终止后停止新增履约和到期续约提醒，未结账款仍可催收及处理，招聘保证期继续处理。账款及在途业务处理完成后结案。
* 草稿、已结案、已作废合同允许删除。有旧生效版本的草稿需先终止并结案。无业务历史及引用的草稿彻底删除，其余采用逻辑删除。

默认列表隐藏已删除合同，勾选「包含已删除」可查询，详情只读。版本、回款、招聘、提成等历史和客户金额统计保留。结案合同发生后续退款、冲销时自动重新显示；曾终止的合同恢复为已终止，其余恢复履约中，处理新产生的余额后再结案。

作废、终止、撤回、删除记录在详情「操作记录」查看，审批在「审批记录」查看。共享财务数据不会随普通合同删除被清空；完整数据清除仍使用「系统 → 特殊功能」，其预览包含合同操作历史。

本地 H2 启动自动升级。已有 MySQL 8 数据库先执行 `back/db/mysql/contract-lifecycle-upgrade.sql`；新增按钮由应用启动幂等注册，保留现有角色权限，不自动开启流程。
